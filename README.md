# 🍽️ Cardápio Digital – Sabor da Bahia

Cardápio digital de um restaurante baiano **fictício**, feito para praticar HTML, CSS e JavaScript.

## Funcionalidades
- Lista de pratos gerada com JavaScript a partir de um array
- Filtro por categoria (Pratos principais, Petiscos, Sobremesas, Bebidas)
- Busca por nome do prato
- Montagem de pedido com quantidade e total calculado automaticamente
- Layout responsivo (celular e computador)

## Tecnologias
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM, eventos, `filter`, `reduce`)

## Como rodar
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador
